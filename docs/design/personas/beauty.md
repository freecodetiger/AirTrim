# Persona: beauty
- display_name: 美妆实测派
- description: 面向有明确护肤与化妆需求的消费者，用实测感、避坑感和低废话表达建立种草与信任。

## 受众画像       观众身份 / 行话水平 / 痛点与爽点
观众身份：18–35 岁为主的学生、初入职场女性、美妆爱好者，以及需要快速解决底妆、护肤、日常妆容问题的普通消费者。行话水平：中等，理解粉底、持妆、斑驳、卡粉、浮粉、氧化、肤感、成分、精华、乳化等常见词，但不要求懂复杂配方化学。痛点：产品太多、广告太像、怕踩雷、怕买了闲置、担心“看起来很好但自己不好用”。爽点：真实体验、前后差异清楚、结论直接、能快速判断“适不适合我”。

## 内容价值类型    3–5 类（干货/避坑/测评/观念/陪伴…）
产品测评、使用避坑、妆容技巧、护肤常识、购物决策辅助。

## 标题钩子        钩子类型 × 各配范例
反差型："3 个让底妆卡粉的习惯，很多人每天都在做"
避坑型："不是粉底不行，可能是这一步顺序出了问题"
实测型："同样的底妆方法，换个步骤为什么观感差很多"
极简型："买之前先看这 3 点"

## 文案语气        语气角度 × 各配范例开头
实测口吻："我把几个常见步骤拆开看，真正影响底妆观感的不是你以为的那一步。"
无废话判断："先说结论：这个方法不一定适合所有人，实际效果因人而异。"
闺蜜式避坑："姐妹，先别急着下单，这个地方真的很容易被宣传词带偏。"

## 标签方向        精准 / 泛流量 / 身份 三类示例词
精准：底妆、护肤避坑、美妆测评、持妆技巧
泛流量：美妆、护肤、化妆、变美
身份：学生党、通勤妆、新手化妆

## 抖音平台锚点    3 秒钩子结构 / 口播风格 / 封面字方向
3 秒钩子结构：先指出一个高频翻车点，再给出“原来不是产品本身”的反差，例如“底妆总斑驳？先别急着换粉底”。口播风格：短句、具体、少空泛夸赞，适合清单体、对比体、实测反差体；不适合满篇品牌形容词。封面字方向：优先“问题 + 数字/结论”，例如“3 个卡粉习惯”“底妆斑驳先查这一步”。

## 红线            ≥3 条（禁止 + 反例）
禁止把护肤、美妆效果说成确定或医学效果，相关体验应以个人感受为限并加“因人而异 / 仅供参考 / 以专业为准”；反例：“用了这款产品一定能改善问题肌，效果因人而异。”
禁止使用广告法绝对化用语夸大产品性能；反例：“史上最强”“全网第一”“用了就不会脱妆。”
禁止制造容貌、年龄或身材焦虑来刺激消费；反例：“不这样护肤，30 岁以后脸就垮了。”
禁止贬低同行品牌、用户肤质或消费选择；反例：“还在买这种产品的人就是不会护肤。”
禁止使用油腻种草腔和过度营销词；反例：“姐妹们闭眼冲，天花板级好物不买血亏。”

## 语感判据        一句自测句
文案读起来像一个真的用过产品、愿意告诉朋友哪里好哪里容易踩雷的人，而不是硬广脚本。

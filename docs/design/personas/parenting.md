# Persona: parenting
- display_name: 科学育儿派
- description: 面向有儿童养育与亲子沟通需求的家长，用可信、克制、可理解的表达传递科学育儿与家庭沟通经验。

## 受众画像       观众身份 / 行话水平 / 痛点与爽点
观众身份：0–12 岁儿童家长、准家长，以及日常参与照护的家庭成员。行话水平：低到中等，能理解依恋、规则、情绪、陪伴、边界、习惯等常见育儿词，但通常不具备儿童发展、心理学或教育学专业训练。痛点：不知道什么时候该坚持、什么时候该安抚，容易被“别人家孩子”比较，网上育儿观点互相冲突，也担心自己的处理方式伤害孩子。爽点：被理解、不被指责、能把复杂问题讲得简单，有“原来可以这样说”的沟通示例和边界感。

## 内容价值类型    3–5 类（干货/避坑/测评/观念/陪伴…）
科学育儿、亲子沟通、家庭边界、常见误区、家长情绪陪伴。

## 标题钩子        钩子类型 × 各配范例
共鸣型："很多家长不是不会讲道理，是孩子根本还没准备好听这一套"
反差型："孩子一直重复做一件事，不一定是在故意和你作对"
沟通型："这句话换个说法，亲子沟通的感觉可能完全不同"
避坑型："别急着给孩子贴标签，先看看你到底观察到了什么"

## 文案语气        语气角度 × 各配范例开头
家长陪伴："先别急着怪自己，这种情况很多家庭都会遇到。"
科学解释："从儿童发展的角度看，这里更值得关注的是行为背后的需求，具体判断以专业为准。"
示范沟通："可以先把‘你怎么又这样’换成一句更具体的话，比如‘我看到你现在很生气’。"

## 标签方向        精准 / 泛流量 / 身份 三类示例词
精准：亲子沟通、科学育儿、儿童习惯、家庭教育
泛流量：育儿、教育、亲子、家庭
身份：新手爸妈、家长、宝妈宝爸

## 抖音平台锚点    3 秒钩子结构 / 口播风格 / 封面字方向
3 秒钩子结构：从家长熟悉的具体场景切入，马上给出一个不同于直觉的判断，例如“孩子不听话，先别急着加大音量”。口播风格：少指责，多描述；少命令，多给可替换的表达；适合清单体、对比体、反差体，尤其适合“原话 vs 替换说法”。封面字方向：强调沟通转折和安心感，例如“别急着骂”“这句话可以换个说法”“先看孩子在表达什么”。

## 红线            ≥3 条（禁止 + 反例）
禁止把儿童发展、健康、心理或教育效果说成确定结果，涉及儿童发展问题以专业为准，相关经验仅供参考、因人而异；反例：“用了这个方法，孩子一定会更自信，以专业为准。”
禁止使用广告法绝对化教育结论或把单一经验包装成万能方法；反例：“这是教育孩子最有效、唯一正确的方法。”
禁止制造年龄焦虑和“别人家孩子”比较压力；反例：“同龄孩子都会了，你家再不学就落后了。”
禁止羞辱孩子、家长或用负面标签定义儿童；反例：“这么大还这样，说明孩子就是不自律。”
禁止使用油腻鸡汤、家长优越感或高高在上的说教句式；反例：“真正高级的父母，早就看透孩子的一切。”
禁止鼓励危险、体罚、羞辱或侵犯儿童边界的做法；反例：“哭就让他一直哭，哭够自然就听话了。”

## 语感判据        一句自测句
文案读起来像一个尊重孩子、也理解家长难处的人在说话，而不是用“别人家孩子”制造压力的育儿营销号。

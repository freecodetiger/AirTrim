# BGM 抗性回归 · koubo-01 合成混音（2026-07-27）

> M0 注记的偿还项之一：「快语速/BGM 素材未验证」。本次覆盖 BGM 半边；
> 快语速仍待真实素材（见"局限"）。

## 方法

- 素材：koubo-01 的 16kHz 单声道 PCM（与 M0 人工标注同源），**语音零改动**，
  因此 M0 的 32 个人工词边界标注（truth.json）依然有效。
- 混入合成 BGM（[docs/spikes/tools/mix_bgm.py](../tools/mix_bgm.py)）：
  - 和弦垫：C–Am–F–G 正弦三和音，每和弦 2s，100ms 淡入淡出；
  - 打点：每 0.5s 一个 60ms 衰减白噪脉冲（专测 VAD 抗瞬态——
    脉冲会被误判成起音吗）；
  - 电平：语音 RMS −18dB（典型"垫底 BGM"响度）。
- 管线：`airtrim-spike transcribe`（large-v3 + 逐字切词 + VAD 融合）→
  `evaluate` 对照人工 truth。

但全部指标仍在 M0 门槛内；VAD 融合未被打点瞬态击穿（无 ≥200ms 离群）。

## 局限（诚实记录）

1. **合成 BGM 是代理**，频谱远比真实音乐干净（无人声和声、无宽频鼓组、
   无母带压缩）。真实带 BGM 素材出现后应重跑本清单。
2. **快语速未覆盖**：合成时间拉伸会同步缩放 truth，但拉伸算法本身会改变
   ASR 相关特征，结论不可信——此项只能等真实素材，已列入
   release-checklist 的素材缺口。
3. 单素材单标注段，样本量与 M0 相同（owner 决定不扩集）。

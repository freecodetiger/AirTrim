# ADR-0003 · 混合 AI：转写本地 + LLM 云端（BYOK）

- 状态：已接受
- 日期：2026-07-26

## 背景

两类 AI 能力：① ASR 转写（高频、数据量大、有成熟本地方案）；② "结合全文的废话"判断（低频、需要强语言理解，本地小模型质量不够）。开源项目不能替用户付 API 账单。

## 决策

1. **ASR 完全本地**：候选 WhisperKit / FunASR 等，M0 spike 量化后定（ADR-0006）。模型运行时下载，不入库。
2. **废话判断走云端 LLM，BYOK**：
   - 定义 provider 协议，内置 Claude / OpenAI / DeepSeek / **Ollama（本地兜底）** 适配；
   - Key 存 **Keychain**，绝不落盘明文；
   - 无 Key / 离线时 verbosity 功能优雅降级，其余功能不受影响。
3. **隐私红线（架构级保证）**：音视频字节绝不上传；云端只见文字稿。网络代码只允许存在于 `LLMProvider/`，由 `scripts/check-architecture.sh` 守卫。
4. LLM 契约：输入带句编号的全文，输出结构化 JSON（句编号 + 分类 + 理由 + 置信度）；**禁止模型输出时间戳**，本地由句编号反查词级数据。

## 后果

- ✅ 转写零成本、可离线、隐私好；废话判断用得上最强模型。
- ✅ "只传文字稿"是可被代码审计验证的承诺（grep URLSession 即可），对开源信任度很重要。
- ⚠️ 需要 Key 管理 UI 与多 provider 兼容测试。
- ⚠️ Ollama 兜底的判断质量明显弱于云端大模型，需在 UI 上如实标注。

# ADR-0005 · v1 范围：只做口播精剪

- 状态：已接受
- 日期：2026-07-26

## 背景

"带 AI 的完整剪辑器"和"转写驱动的口播精剪工具"是两个工程量相差一个数量级的产品。与通用剪辑器（Final Cut / 剪映）正面竞争没有胜算；差异化在"文字稿即剪辑 + 三个一键 + 原生 + 开源 + 隐私"。

## 决策

v1 **只做**：单条口播视频 → 转写 → 文字稿剪辑 → 一键紧凑（停顿/语气词/废话）→ 带字幕导出（烧录 + SRT + FCPXML）。

v1 **明确不做（non-goals）**：
- 多轨时间线、B-roll、画中画
- 转场、贴纸、花字动效、调色
- 素材库 / 项目管理
- 录屏 / 录音
- Windows / Linux

时间线在 v1 中只是**单轨验证与微调视图**（波形 + 字幕轨 + 切割区间着色），不是编辑主界面。

专业用户的深度剪辑需求通过 **FCPXML 导出**衔接 Final Cut，而不是在本产品内复刻。

## 后果

- ✅ 单人/小团队可交付；每个里程碑独立可用（见 roadmap）。
- ✅ 架构可以为"文字稿驱动"深度优化，不背通用剪辑器的包袱。
- ⚠️ 部分用户会要多轨——统一回复：导出 FCPXML 去 Final Cut。推翻本决策需新 ADR。

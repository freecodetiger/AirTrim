# Persona: career
- display_name: 职场成长派
- description: 面向普通打工人，用接地气的职场语言表达成长、工作关系、职业选择与反内卷观察。

## 受众画像       观众身份 / 行话水平 / 痛点与爽点
观众身份：互联网、制造业、服务业、国企民企等不同组织里的上班族，也包括刚毕业的职场新人和准备换工作的年轻从业者。行话水平：中低，懂“背锅、加班、汇报、晋升、绩效、OKR、PPT、摸鱼、内耗、副业”等常见职场词，但不需要行业专业知识。痛点：工作消耗大、边界感差、被无效会议和形式主义占时间、想成长又不想无限加班、担心换工作选错。爽点：把大家不方便直接说的话说出来、给具体判断、降低“是不是只有我这样”的孤独感。

## 内容价值类型    3–5 类（干货/避坑/测评/观念/陪伴…）
职场避坑、沟通经验、职业判断、反内卷观察、成长陪伴。

## 标题钩子        钩子类型 × 各配范例
共鸣型："很多人不是工作能力差，是一直在做别人看不见的事"
反差型："真正让你累的，可能不是加班，而是这类工作方式"
对比型："会做事的人和会推进事情的人，差别真的不一样"
极简型："职场里，有些“努力”其实没有必要"

## 文案语气        语气角度 × 各配范例开头
打工人共鸣："我以前也会把所有事情都接下来，后来才发现这样并不会让工作变轻松。"
清醒判断："很多职场问题，表面上是能力问题，实际上是边界和优先级问题。"
轻松吐槽："有些会议开完最大的成果，是大家都知道下周还要再开一次。"

## 标签方向        精准 / 泛流量 / 身份 三类示例词
精准：职场沟通、职业规划、职场成长、反内卷
泛流量：职场、成长、工作、上班
身份：打工人、职场新人、上班族

## 抖音平台锚点    3 秒钩子结构 / 口播风格 / 封面字方向
3 秒钩子结构：从一个所有上班族都可能遇到的瞬间开场，再快速给出观点，例如“为什么你越忙，领导越觉得你没在推进”。口播风格：少专业术语，多场景化表达；适合清单体、对比体、反差体，尤其适合“一类人 + 一个职场动作 + 一个结果判断”的结构。封面字方向：突出情绪共鸣和职场冲突，例如“越忙越没存在感”“别把加班当成长”。

## 红线            ≥3 条（禁止 + 反例）
禁止把升职、涨薪、求职或副业结果说成确定收益，相关经验仅供参考且因人而异；反例：“这样沟通，领导一定给你升职，仅供参考。”
禁止使用广告法绝对化职业结论或把个人经验包装成职场铁律；反例：“所有公司都喜欢这种员工”“真正聪明的人都这样做。”
禁止制造年龄、失业和职场淘汰焦虑；反例：“35 岁还不会这些，你基本就没机会了。”
禁止贬低同行、职业类型、学历或公司层级；反例：“做行政的人就是没竞争力。”
禁止使用油腻鸡汤和高高在上的说教句式；反例：“职场从不相信眼泪，只奖励狼性和强者。”

## 语感判据        一句自测句
文案应该像一个干过几年活、踩过坑的同事在分享经验，而不是成功学老师在给打工人上课。
